# ModbusTCP_RU 0.3.0

Архив `ModbusTCP_RU.zip` содержит исходники, примеры, схемы и README библиотеки.

## Установка

1. Arduino IDE: Скетч -> Подключить библиотеку -> Добавить .ZIP библиотеку.
2. Установить `Ethernet >= 2.0.2` через менеджер библиотек.
3. Открыть пример из `Файл -> Примеры -> ModbusTCP_RU`.

При ручной установке папка `ModbusTCP_RU` должна находиться в `Documents/Arduino/libraries`. Внутри неё остаётся папка `src`; переносить файлы из неё в корень не нужно.

## Что изменилось

Только Slave для SCADA. Исправлены TCP-соединения и проверка запросов; добавлены согласованная конфигурация и runtime-таймауты. Порядок перехода с 0.2.x описан в основном README.

Для быстрого старта: `relay_slave_lite`. Для восстановления линка W5500: `relay_slave_watchdog`. Ограничения испытаний указаны в основном README.
